new prototype direction

A calmer dark interface for login, user and admin.

这套原型只保留深 slate 层次、暖 amber 点亮、半透明卡片和很轻的交互反馈。 前面的 Maximalism 和 Vaporwave 不再沿用。

style summary
Layered dark

`#0A0A0F → #12121A → #1A1A24` 三层暗色，避免纯黑。

Warm accent

只用 amber 做主点缀，不再用高饱和霓虹色。

Quiet motion

按钮和卡片只保留 200~300ms 的轻微反馈。
